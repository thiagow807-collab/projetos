# Brasa & Pão — Landing page para lanchonete

Página de vendas responsiva feita com HTML, CSS e JavaScript puro.

## Como visualizar
Abra o arquivo `index.html` no navegador. Também é possível publicar gratuitamente pelo GitHub Pages.

## Personalizações importantes antes de divulgar
1. **WhatsApp:** abra `script.js` e troque `WHATSAPP_NUMBER` pelo número real, com código do país, DDD e número, sem espaços ou símbolos. Exemplo: `5547991234567`.
2. **Nome e identidade:** procure por “Brasa & Pão” no `index.html` e substitua pelo nome da sua lanchonete.
3. **Produtos e preços:** os itens e valores atuais são exemplos. Edite os cards no `index.html` e mantenha os atributos `data-product` e `data-price` dos botões.
4. **Informações comerciais:** atualize descrição, atendimento, endereço, horários e redes sociais conforme os dados reais do negócio.

## Estrutura
- `index.html`: conteúdo, seções, cardápio e estrutura da página.
- `styles.css`: identidade visual, layout e responsividade.
- `script.js`: filtros do cardápio, carrinho e integração de pedido via WhatsApp.

## Observação
O carrinho monta a mensagem do pedido e abre o WhatsApp. Não há pagamento online, cálculo de frete ou envio automático para um sistema de pedidos. Os emojis e ilustrações são elementos visuais de demonstração.
